# Менеджмент — Практика

Сайт для подготовки к магистратуре по менеджменту. В базе 3569 вопросов из предоставленного TXT-файла, точные дубликаты удалены.

## Возможности

- Обучение: 10, 20 или 50 вопросов с показом правильного ответа.
- Экзамен: случайные вопросы, 30 минут, результат после завершения.
- Повторение ошибок и продолжение незавершённой тренировки.
- Локальное сохранение прогресса, экспорт и импорт JSON.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск

Нужен статический HTTP-сервер. Например, из папки проекта:

```bash
python -m http.server 8000
```

Открыть http://localhost:8000. Сборка и npm-зависимости не нужны.
Не открывайте index.html напрямую через file://: загрузка questions.json требует HTTP.

## Файлы

- index.html — страница.
- style.css — оформление.
- app.js — логика тренажёра.
- questions.json — вопросы и правильные ответы.

Для статического хостинга загрузите эти четыре файла в одну папку. Внешний Google Fonts необязателен: при недоступности используется системный шрифт.

Прогресс хранится только в браузере на устройстве пользователя. Для переноса используйте экспорт и импорт. В исходниках нет пользовательского прогресса.

Учебный режим экзамена не является официальной симуляцией вступительного экзамена. Правильные ответы перенесены из исходного файла и отдельно не проверялись на соответствие актуальной программе.
